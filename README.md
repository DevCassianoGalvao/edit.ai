# Edit.AI by Galvão

Aplicação local para Windows voltada à montagem de vídeos com narração, imagens, vídeos e ferramentas de IA instaladas no computador. Consulte LEIA-ME-NESTE-PC.md para instruções e limitações.

Este repositório é uma cópia de código e recursos da instalação local. Chaves, histórico, memória editorial, produções, bibliotecas de mídia e dependências instaladas não são incluídos. Alguns fluxos herdados dependem desses arquivos e de configuração local; não há garantia de instalação reproduzível ou produção completa a partir deste repositório. Antes de usar em outro PC, revise os caminhos locais e configure as integrações.
